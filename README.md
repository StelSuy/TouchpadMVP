# Touchpad MVP — Android

Телефон как тачпад для ПК. Приложение отправляет жесты по TCP, маленький сервер на ПК (`pc_server/`) превращает их в события мыши и клавиатуры.

## Возможности

**Жесты (каждый отключается в Настройках)**

| Жест | Действие |
|---|---|
| 1 палец — двигать | курсор (с настраиваемым ускорением) |
| 1 палец — тап | левый клик |
| тап, затем сразу коснуться и вести | перетаскивание / выделение текста |
| удержать палец на месте | зажать левую кнопку (вибро-отклик), вести — выделять |
| 2 пальца — тап | правый клик |
| 2 пальца — вести | прокрутка вертикальная и горизонтальная (натуральная или классическая) |
| 2 пальца — свести / развести | масштаб (Ctrl + колесо) |
| 3 пальца — тап | средний клик |
| 3 пальца — свайп ↑ ↓ ← → | 4 действия на выбор: обзор окон, рабочий стол, Alt+Tab, виртуальные рабочие столы, назад/вперёд, вкладки, закрыть/свернуть/развернуть окно, скриншот, блокировка, пауза |

**Остальное**
- панель быстрых клавиш: Esc, Tab, Backspace, Enter, стрелки, копировать/вставить/вырезать/выделить всё/отменить, Alt+Tab, Win, громкость, медиа, скриншот, блокировка;
- ввод текста с экранной клавиатуры телефона (кириллица и любые символы работают);
- кнопки громкости телефона могут менять громкость на ПК;
- «Найти ПК» — автопоиск сервера в Wi-Fi (UDP broadcast);
- пароль на подключение, автоподключение к последнему ПК (в т.ч. после обрыва);
- чувствительность, ускорение, скорость прокрутки, вибро-отклик, «не гасить экран»;
- скрытие панели быстрых клавиш и кнопок кликов.

## Сервер на ПК (Windows)
Нужен только Python 3, сторонние библиотеки не нужны.

1. Запусти `pc_server/start_server.bat` (или `python server.py --port 5000 --password СЕКРЕТ`).
2. Телефон и ПК — в одной Wi-Fi сети.
3. В приложении нажми «НАЙТИ ПК» или введи IP, который показал сервер.
4. При первом запуске Windows спросит про брандмауэр — разреши доступ для частных сетей
   (нужны входящие TCP и UDP на порт 5000).
5. Если задал `--password` — впиши тот же в Настройки → Соединение.

> Без пароля любой в вашей Wi-Fi сети сможет управлять ПК, пока сервер запущен. В публичных сетях используй пароль.

## Протокол
Текстовые строки UTF-8 по TCP, каждая заканчивается `\n`.

```
HELLO|<пароль>          -> OK|<имя ПК>  или  AUTH_FAIL   (обязательно первой строкой)
MOVE|dx|dy              движение курсора (дробные пиксели, точка как разделитель)
CLICK|LEFT|RIGHT|MIDDLE
DOWN|LEFT  /  UP|LEFT   зажать / отпустить кнопку
SCROLL|h|v              прокрутка в щелчках колеса (v>0 — вверх, h>0 — вправо)
ZOOM|n                  Ctrl + колесо, n щелчков
HOTKEY|CTRL+SHIFT+T     комбинация клавиш
TEXT|<urlencoded>       ввод текста
```
UDP: запрос `TOUCHPAD_DISCOVER` → ответ `TOUCHPAD_HERE|<имя ПК>`.

## Сборка в Android Studio
1. Открой папку проекта, дождись Gradle Sync (JDK 17).
2. Подключи телефон с USB-отладкой и нажми Run ▶.

## Структура
- `GestureEngine.kt` — распознавание жестов, не зависит от Android;
- `TouchpadView.kt` — передаёт касания в движок;
- `Settings.kt`, `Prefs.kt`, `SettingsActivity.kt`, `res/xml/preferences.xml` — настройки;
- `MouseClient.kt` — TCP-клиент, пароль, автопоиск;
- `MainActivity.kt` — экран, быстрые клавиши, ввод текста.
