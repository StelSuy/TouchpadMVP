# Touchpad MVP — Android

Минимальный Android-клиент для превращения телефона в тачпад ПК.

## Что уже есть
- сенсорное поле;
- движение курсора через TCP;
- короткий тап = левый клик;
- кнопки Left / Right Click;
- IP и порт ПК;
- подключение/отключение без сторонних сетевых библиотек;
- Java/Kotlin JVM target **17**, чтобы не повторить ошибку `Java 1.8 vs Kotlin 21`.

## Протокол MVP
Приложение открывает TCP-соединение с ПК и отправляет UTF-8 строки:

- `MOVE|dx|dy`
- `CLICK|LEFT`
- `CLICK|RIGHT`

Каждая команда заканчивается `\n`.

Пример:
```
MOVE|4.20|-2.10
CLICK|LEFT
```

## Сборка в Android Studio
1. Открой папку `TouchpadMVP`.
2. Дождись Gradle Sync.
3. Подключи Android-телефон с USB debugging или запусти эмулятор.
4. Нажми Run ▶.

Если Android Studio предложит выбрать JDK — используй **JDK 17**. В проекте Java и Kotlin принудительно выставлены на JVM 17.

## Сервер на ПК (Windows)
Лежит в `pc_server/`. Нужен только Python 3, сторонние библиотеки не нужны.

1. На ПК запусти `pc_server/start_server.bat` (или `python server.py --port 5000`).
2. Сервер выведет IP-адреса ПК, например `192.168.1.25:5000`.
3. Телефон и ПК должны быть в одной Wi-Fi сети.
4. При первом запуске Windows спросит про брандмауэр — разреши доступ для частных сетей
   (или открой входящий TCP-порт 5000).
5. В приложении введи этот IP и порт, нажми «ПОДКЛЮЧИТЬ».

## Что исправлено
- краш при запуске (`TouchpadView` не имел конструктора для XML);
- битый URL в `gradle-wrapper.properties`, добавлены `gradlew`/`gradle-wrapper.jar`;
- формат чисел зависел от локали (`4,20` вместо `4.20`);
- `TCP_NODELAY` — курсор больше не лагает;
- статус сбрасывается при обрыве соединения;
- отступы под статус-бар на Android 15.
